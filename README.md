Учебный проект по автоматизации тестирования сайта «mattioli.by»  включающий реализацию UI и API.

Автор: Говядина Ирина

Описание архитектуры, функционала и используемых технологий в проекте 


Ключевые модули тестирования
Форма логина
 -  попытки входа с несуществующими учётными данными;
 - обработка пустых полей ввода (email, password)

Строка поиска
- проверка отображения заголовка;
- тестирование ввода товаров и корректности результатов

API-интерфейсы
- валидация статус-кодов ответов;
- верификация запросов и получаемых данных
